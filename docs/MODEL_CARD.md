# 模型卡

用途：固定网络拓扑的未来链路负载预测，为影子模式调度提供输入。

训练数据：1600 步程序模拟遥测，9 条无向链路，seed=42；65/15/20 时间切分。模型输入是历史 32 步链路利用率，输出未来 6 步。标准化只用训练段。模型 6126 参数。

评估：测试 MAE=0.03250，RMSE=0.04758；仅单种子，无外部数据、无置信区间。完整指标及数据哈希保留在 artifacts。

限制：模拟数据分布过于有限，拓扑固定；无法覆盖跨网、突发故障和长期漂移；预测误差可能导致容量超限。没有生产控制能力。

可追溯：训练代码、验证损失曲线数据、模型权重、ONNX 和预处理元数据共同保存。不同平台线程 / 算子可能有微小差异。
